    AI-Powered Job Search Agent

    In ProgressLocal MVP: October 23, 2026Cloud target: October 30, 2026

    A Python application designed to retrieve job opportunities, compare descriptions against an applicant's resume and preferences using an LLM, and produce a ranked, explainable HTML report.

    View roadmap ↓ GitHub Repository Download ZIP

    Project Overview

    The agent will accept a PDF or DOCX resume and job-search preferences, collect job listings from supported sources, normalize and deduplicate the results, evaluate fit using a large language model, and create a report containing scores, explanations, gaps, and links to apply.

    Delivery approach: Phase 1 is a locally executed MVP. Phase 2 evaluates AWS and GCP and targets a cloud-hosted release. Dates below are targets, not completed claims.

    Proposed Solution Architecture

    InputsResume + preferences
    DiscoveryDice MCP / Adzuna API
    Data processingNormalize + deduplicate
    AI evaluationLLM fit + evidence
    OutputRanked HTML report

    Architecture shown is the target workflow. Cloud hosting and LLM scoring are not yet claimed as implemented.

    LLM-based job fit evaluation

    Planned evaluation includes required skills, relevant experience, responsibilities, seniority, preferred qualifications, and career alignment. Scores will be accompanied by evidence and missing qualifications. Hard constraints such as location or work arrangement will be assessed separately.

    Cloud architecture — Phase 2

    An architecture spike will compare AWS and GCP on deployment simplicity, operating cost, security, logging, secrets management, and suitability for a small Python application. The decision and deployment design will be documented in an architecture decision record (ADR).
